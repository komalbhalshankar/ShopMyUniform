# ShopMyUniform 🎓

ShopMyUniform is a full-stack school uniform e-commerce web application designed to make buying school uniforms simple and convenient for students and parents.

## 🚀 Features

### 👨‍🎓 User Features

- User registration and login
- Student and parent roles
- Browse school uniform products
- Search products
- View product details
- Add products to cart
- Update cart quantities
- Remove products from cart
- Checkout and place orders
- View order history
- Track order status
- User profile

### 👨‍💼 Admin Features

- Admin authentication
- Admin dashboard
- Dashboard statistics
- View registered users
- Delete users
- Product management
- Add new products
- Edit products
- Delete products
- View all orders
- Update order status
- Order management

### 🤖 Support Assistant

- Integrated ShopMyUniform support assistant
- Helps users with products, sizes, orders, delivery, returns and exchanges

---

## 🛠️ Tech Stack

### Frontend

- React.js
- React Router
- Axios
- Vite
- CSS

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
